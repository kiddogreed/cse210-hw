# W07 Assignment: Explain Programming with Classes

For me, programming with classes utilizing Object-Oriented Programming includes:

* **Encapsulation:** Data hiding using the `private` keyword, ensuring other programs cannot modify it directly.
* **Inheritance:** Enabling reusable methods and attributes to save time and avoid repetition.
* **Polymorphism:** Being able to make dynamic methods that respond depending on the context and the situation needed.
* **Abstraction:** Allowing us developers to lay out the concept without focusing too much, then later implementing it depending on the situation needed.

By utilizing these features, we allow ourselves to collaborate with other developers and handle larger projects.
